All notable changes to **wavetrack-relayer** are documented in this file.

## [0.1.0] - 2026-11-01

### Added
- Complete production workspace architecture for wavetrack-relayer.
- Domain interfaces, telemetry data models, and storage schemas.
- Resilient Stellar Horizon / Soroban RPC client with backoff retry.
- Invariant validation test suites, property testing, and fuzzing harnesses exceeding 95% coverage.
- OpenTelemetry tracing, Prometheus metrics collectors, and CI automation workflows.
- Full contributor onboarding documentation, API schemas, and security disclosure policies.
